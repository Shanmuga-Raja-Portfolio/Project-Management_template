pmkit

Project setup for AI coding agents: a short interview, a proposal you approve, and only the files you'll keep up.

pmkit sets up a project folder for your AI agent or chat model. It asks a few questions, shows you a proposal, and creates only the files you approve. Tools are optional and added later, only when a real need shows up.

Three ways to start

  1. Paste a RUNFILE into any chat. No install. Each level has one self-contained prompt: copy it from the repo and answer the questions. Level 1, 2 and 3 RUNFILEs.
  2. Claude Code skill. Clone the repo, run bash scripts/install-skill.sh (or the .ps1 on Windows), then say "set up this project" in your project folder.
  3. Copy the starter files yourself. bash scripts/new-project.sh --minimal /path/to/project copies the five core files. Existing files are never overwritten.

Pick your level

LevelSuitsTime
1. Starter Most people. The safe default. Eight short questions, no tools.5–15 min
2. Starter + tools Code or document-heavy projects. Adds opt-in, ask-first installers for light tools.15–40 min
3. Interview-led Larger projects, handoffs, inherited repos. Full interview; plan only, or plan plus files.30–60 min

Not sure? START-HERE.md asks three questions and picks for you. Browser chat only (ChatGPT, Claude.ai, Gemini)? You need just three small files — see the chat window guide.

Privacy: every tool card lists the network calls a tool makes and the files it touches. Installers never ask for or store API keys. Nothing is sent to a cloud model unless you say it may.
